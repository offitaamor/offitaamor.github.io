# OFFITA AMON WEBSITE — V1

완전 무료로 시작할 수 있는 정적 포트폴리오 홈페이지입니다.

## 파일
- index.html — 메인 홈페이지
- assets/style.css — 전체 디자인
- assets/script.js — 모바일 메뉴 및 연도 표시
- assets/logo.svg — V1 워드마크

## 로컬에서 열기
`index.html`을 더블클릭하면 브라우저에서 바로 확인할 수 있습니다.

## 무료 배포
### GitHub Pages
1. GitHub에서 새 public repository 생성
2. 이 폴더의 파일을 업로드
3. Settings → Pages
4. Deploy from a branch 선택
5. main / root 선택
6. 생성된 `username.github.io/...` 주소 사용

### Cloudflare Pages
GitHub 저장소를 Cloudflare Pages에 연결하여 무료 배포할 수 있습니다.
